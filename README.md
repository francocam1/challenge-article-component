## 🛠️ Lo técnico
* **Estructura:** HTML5 semántico y CSS (Flexbox + Posicionamiento).
* **Responsive:** Diseño adaptativo para Mobile y Desktop mediante Media Queries.
* **Lógica:** JavaScript para alternar la visibilidad del menú de compartir (`classList.toggle`).
* **Estética:** Transiciones suaves en hovers y estados activos para mejorar la experiencia.
